# 本机测试步骤

打开 http://127.0.0.1:5188/ ，底部应显示“资料已保存到本机”和“AI 已配置”。连接失败时使用 `npm run dev` 启动前后端。

## 先测试保存与素材

1. 在“图片工作台”填写妆容描述，保存为项目；刷新页面，检查项目与描述仍在。
2. 在“作品库”导入 JPG、PNG 或 WebP，刷新后打开详情和下载原图。
3. 在“虚拟模特”创建档案，选择刚导入的图片并填写人物描述。将来生成时，这张图片会作为人物参考传给供应商。
4. 收藏素材、切换作品筛选，检查结果正确。

项目与图片保存在本机应用数据目录，浏览器另留草稿副本。系统钥匙串保存服务密钥。

## 三语文案

1. 从“作品库”选择一个作品组，进入“三语文案”，点击“生成未锁定语言”。该操作会实际调用服务。
2. 等待任务显示“已完成”，分别检查中文、英文、韩文。
3. 修改中文并锁定，再次生成未锁定语言，确认中文保留。
4. 也可以选择“接口验证 · 虚拟模特”，查看开发验收时真实生成的三语文案。

## 图片与修图

当前图片模型是 `gpt-image-2`，文案模型为 `gpt-6.1-sol`。最新单张生成已成功，作品库中的“韩系清透 · 1”为真实生成结果。旧任务中的分组权限错误是历史记录。

图片测试步骤：

1. 虚拟模特模式，填写描述，先选 **1 张**，点击生成。
2. 查看真实任务状态。成功后图片会出现在“我的素材”和作品库；刷新后应仍可查看。
3. 照片修图模式必须选择原始照片，填写修改说明，再点击“开始修图”。
4. 多张任务可取消剩余生成；正在处理的一张仍可能完成并产生费用。

接口失败会显示真实错误。超时或服务中断后，先检查供应商记录，再决定是否手动重试，避免重复生成。

## 导出与排期

“设置与连接”可导出资料清单，或导出包含有效原图的 JSON 备份；后者带有校验值，不包含密钥。当前尚无备份导入与恢复按钮。

发布排期只保存草稿。Instagram 授权、实际发布和自动定时执行仍待接入。

## 新增：随机人物与作品组

1. 在图片工作台的模特选择器选择“随机模特”。
2. 身份、年龄、国家／地区、人种／外观和着装均为选填；留空由 AI 自由设定成年人物。每项支持“随机”，也可点“全部随机”。选择已有模特时，这组字段隐藏。
3. 选择四类中的任一妆容风格，点击“按风格随机描述”。检查描述包含当前人物字段及所选妆容，再使用“AI 润色”或手动修改。
4. 生成 2 张时，第二张会参考本组第一张，保留人物与妆造，并变化角度或姿势。随机人物在首张成功后自动存入模特库。
5. 打开作品库，按“作品组”浏览，进入一组后点击“为整组写文案”。一组图片共用一套中英韩文案，支持多图预览与语言锁定。

本轮真实验收新增了“港风红唇”两张作品，以及“律师 · 32岁”的模特档案。该组的三语文案已经生成，可直接查看。

## 提示词中心

1. 点击侧栏“提示词中心”，查看“共享库／我的收藏／生成记录”。当前功能在本地运行。
2. 在生成记录里打开之前的任务，查看创作描述和图片。旧任务会注明当时没有记录完整请求。
3. 下一次正常生成图片或修图后，在记录详情切换“实际发送提示词”，检查每张请求的完整内容、参考图顺序及对应结果。失败或取消的记录也保留。
4. 填写效果评价和观察笔记，保存后刷新确认仍存在；满意的描述可点“收录到共享库”，设置标题、标签和使用心得。
5. 在共享库搜索、收藏、编辑提示词，点击“应用到工作台”，确认描述填入，人物选择与参考图保留，再自行决定是否生成。
6. 从共享条目详情导出分享文件，再通过“导入”选择此文件，确认内容后保存。也可新建一条自己的提示词。
7. 作品详情和任务面板均能直接进入对应生成记录。设置页的资料导出及完整备份也包含全部提示词记录与共享库。

## 优质参考、图片反推和加权评测

1. 进入“提示词中心 → 优质参考”，查看已导入的暖棕蜜桃、冷调猫眼、粉调亮片晚宴三组；共享库中也能找到对应反推提示词。
2. 打开一组，查看反推描述、五项观察和 AI 建议评分。原始提示词未知，页面明确显示为视觉分析。
3. 点击“采用建议评分”后可修改单项分数，点“保存评价与规则”后查看加权总分；也可直接手动评分。每项 0–5，留空表示未评或不适用。
4. 点击“评测权重”，调整侧重点、最低分和参考数量。也可关闭自动参考；改变规则不会触发新的付费分析。
5. 添加自己的参考组，选择或上传 1–8 张图，保存后点击“从图片反推提示词”。该操作会调用已配置的文本模型并发送本组图片；建议分不会自动冒充人工评分。
6. 在图片工作台随机描述、润色或正常出图。进入对应生成记录，查看采用的优化方向、当时权重及完整发送提示词。人物设定、服装和所选妆容应保留。
7. 也可为生成记录填写加权评分并标记“效果满意”，让它成为后续优化候选。不同风格的参考会借鉴摄影技法，保留当前妆容要求。

## 每次生成选择图片模型

1. 打开“图片工作台”，在妆容描述下方找到“图片模型”，选择 GPT Image 2、GPT Image 2.5 Flare 或 GPT Image 2.5 Sunburst。选项按当前服务实际目录显示；新模型未显示时可到“设置与连接”测试连接刷新目录。
2. 刷新页面或保存后重新打开项目，确认选择保留。“使用默认”跟随设置中的默认图片模型。
3. 填写描述并生成图片。在任务面板和“查看提示词”中确认实际模型，整批图片应使用同一模型。
4. 切换到“照片修图”，选择原始照片和图片模型，提交后同样核对记录。
5. 工作台切换模型不会更改设置中的默认模型。当前服务不再提供的旧选择会显示提示并阻止提交，重新选择后可继续。

上述生成与修图会调用所选图片服务并产生对应费用；本轮自动和浏览器验收使用独立模拟服务验证模型传递，没有批量调用真实 2.5 生图。

## 放大检查照片

1. 在作品库或图片工作台打开作品详情，点击照片或右下角“放大查看”。
2. 滚轮缩放时将鼠标放在需要检查的细节上；放大后按住鼠标拖拽移动。触摸屏可双指缩放并移动。
3. 点击“原始尺寸”以 100% 查看原图，或点“适应窗口”恢复全图；双击也可放大／还原。最高缩放 800%，不会越过图片边界拖成空白。
4. 快捷键：＋／－ 缩放、方向键移动、1 原始尺寸、0 适应窗口、Esc 返回作品详情。关闭大图会保留原有详情和页面位置。

## 更多参考图与快速工作流

1. 在图片工作台选择任一种妆容风格，参考区默认跟随当前风格；也可用右侧筛选选择其他风格或全部风格。24 种风格各有 2 张新增 AI 参考，部分风格另保留摄影参考。
2. 打开 AI 参考详情，放大检查妆面，点“查看参考提示词”，再点“用这套提示词创作”，确认风格、参考图和描述带入创作台。
3. 进入新菜单“快速工作流”，Step 1 选择参数并生成；提交后自动进入 Step 2，逐张显示本批作品。也可点击“从作品库继续”，选择已有作品组或导入一组照片。
4. Step 2 勾选要发布的图片、设置封面和顺序。清空选择后不能进入下一步。Step 3 只使用选中图片生成三语文案，手工修改后切换语言或刷新，内容和当前步骤应保留。
5. Step 4 检查语言、图片顺序和文案，选择计划时间，保存发布草稿。进入发布排期，应看到这份草稿及其图片；“继续快速工作流”能返回。
6. 导出发布素材包，解压后检查 `01-cover.*`、后续图片、`caption.txt` 和 `publication.json`。原图顺序与 Step 2 一致，文案是保存时的快照，状态为本地草稿。
7. 可在手机宽度继续上述步骤。退出再进入工作流，已选作品、顺序、语言和时间应保留。Instagram 尚未连接，当前不会实际发布。
