# 工作台界面方向

2026-10-22，根据用户对初版“AI 味道太重”的反馈调整整体界面。

## 视觉

- 使用米白与暖灰作为底色，炭黑用于主要操作，棕色只用于选择状态与少量强调。
- 采用普通中文标题和清晰的文字层级，移除英文宣传标语、装饰星芒和 NEW 徽标。
- 缩小圆角、取消悬浮阴影和图片缩放，让表单、导航与分隔线构成页面结构。
- 删除创作台大幅宣传横栏和重复的引导卡片，直接呈现创作设置与参考图片。
- 模特与作品图片保持原有内容，减少图片上的常驻按钮，悬停或键盘聚焦时显示操作；窄窗口直接显示。

## 文案

导航使用“图片工作台”，模式使用“虚拟模特 / 照片修图”。按钮直接说明操作，例如“使用示例”“生成图片”“保存项目”。空状态说明缺少的内容与下一步操作，不使用宣传语。

AI 服务状态、参考示例来源、本地数据库保存和排期草稿的说明继续保留。视觉简化不隐藏必要的状态信息。

## 数据

本次调整仅涉及界面与示例素材标题。业务对象 ID、存储键和数据格式保持兼容，已有项目、文案与图片无需迁移。
