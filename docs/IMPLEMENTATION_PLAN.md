## 后续阶段

1. 验证参考人物一致性、真实照片编辑质量与多张生成。
2. Electron 容器、安全 IPC、安装包及本地服务生命周期管理。

5. 发布状态机、账号隔离、定时调度和异常恢复。

## 数据实现

工作空间当前以校验后的 JSON 聚合存入 SQLite，素材、任务、服务配置、项目归档和审计事件独立存表。版本检查和事务保护修改；后续可按查询需求拆分工作空间领域表。

图片原图及缩略图保存为本机文件。API 密钥仅进入 macOS 钥匙串；非 macOS 使用进程内凭据。浏览器保留草稿副本和同步检查点，不再承担原图的主要存储。

详见 [测试记录](TEST_REPORT.md)、[用户测试步骤](TEST_GUIDE.md) 和 [README](../README.md)。
