# 悦妆师 · YueZhuang Studio

面向化妆师的本地 AI 内容工作台。当前版本已连接本地后端，可保存项目、管理图片、创建虚拟模特参考档案，并调用兼容服务生成图片或中英韩文案。

## 启动

需要 Node.js 20.19+ 或 22.12+，推荐 macOS。

```bash
npm ci
npm run dev
```

打开 **http://127.0.0.1:5188/**。前端为 5188，本地后端为 5189；两者仅监听本机。固定端口被占用时会报错，不会自动切换地址。

```bash
npm test
npm run typecheck
npm run build
```

检查构建后的完整应用：先停止开发后端，再运行 `npm start`，访问 **http://127.0.0.1:5189/**。`npm run preview` 只预览前端构建文件，不启动后端。

## 创作、作品组与文案

- 同批生成或同批导入的图片自动组成作品组。作品库默认按组浏览，可从组卡片、组内页面或单图详情进入三语文案。
- 点击作品详情中的照片可进入大图查看，使用原图查看妆面细节。支持鼠标位置滚轮缩放、双指缩放、放大后拖拽移动、双击放大／还原、原始尺寸与适应窗口，最高放大到 800%；Esc 返回作品详情。
- 一组图片共用一套中英韩文案，适合一条多图帖子。生成时会读取本组图片，支持语言锁定、多图预览和整组导出。
- 24 种妆容风格分为清透日常、氛围妆容、场景造型和创意大片。
- 每种风格新增 2 张 AI 写实参考图，共 48 张；加上保留的 6 张摄影示例，每种风格有 2–3 张参考。工作台默认展示当前风格，可按全部风格筛选。AI 示例明确标注来源，可查看生成时的提示词并一键复用；列表读取缩略图，放大时使用原图。
- 图片工作台可为每次生成或修图选择图片模型。选项来自当前服务目录，包括 GPT Image 2、GPT Image 2.5 Flare 和 GPT Image 2.5 Sunburst；也可使用设置中的默认模型。选择随创作参数和项目保存，同批图片固定使用提交时的模型，任务和提示词记录保留实际模型。切换不会修改服务默认配置；旧项目使用默认值，不可用的旧选择需重新选择。
- 全部风格示例、随机描述、AI 润色和最终出图默认按真实人像摄影处理，强调自然肤质、可信光线与真实衣料，抑制磨皮蜡感和 CG 人偶感；图片请求使用高质量。手写描述和旧项目再次生成时也生效，修图仍保留未要求改动的部分。
- “按风格随机描述”结合人物设定、风格配色、光线和构图；“AI 润色”保留原有要求，并可参考已有模特的图片。可撤回 AI 改写，生成期间的人工修改不会被直接覆盖。
- 选择“随机模特”时，身份、年龄、着装、国家／地区、人种／外观均为选填；留空由 AI 自由设定成年人物，已填内容作为生成约束。各项可单独随机，也可全部随机。选择已有模特时隐藏这些字段。
- 随机描述明确组合上述人物字段和所选妆容；首张图片成功后自动建立模特档案，组内后续图片以首图为人物和妆造参考。

已有图片根据原任务批次归组；旧项目文案保留，并迁移一份到项目封面所属的作品组。升级前已在本机创建数据库备份。

## 快速工作流

侧栏新增“快速工作流”，四步共用同一作品组，进度自动保存：

1. **生成图片**：复用图片工作台，提交后自动进入确认作品；也可跳过生图，选择已有作品组或导入照片。
2. **确认作品**：选择发布图片、调整顺序和封面。最多 20 张，进入下一步时固定所选图片；空选图不能继续。
3. **三语文案**：只将所选图片发送给文案服务，整组共用一套中英韩文案，保留语言锁定和人工修改。选择的发布语言会带到下一步。
4. **发布准备**：预览多图帖子，保存本地排期草稿，或导出原图、文案、排期信息组成的 ZIP。草稿保存图片顺序和文案快照，后续编辑需重新保存才会替换；不需要额外新建项目。

作品组卡片、作品详情和发布日历均可继续工作流。Instagram 授权与实发尚未接入，最后一步明确显示本地草稿状态，不会向外发布。

新增参考图使用内置 imagegen 生成，文件位于 `public/images/examples/`，完整提示词位于 `public/images/examples/prompt-set.json`；安装与清单整理脚本仅复制、生成缩略图和整理元数据，不包含 API 密钥或联网调用。

## 提示词中心

侧栏的“提示词中心”提供共享库、我的收藏、生成记录和优质参考，当前仅在本地运行，不连接在线社区。

- 共享库支持新建、编辑、搜索、标签、作者、使用心得、收藏和应用到工作台，也可导出单条分享文件或导入文件后整理保存。不同本地浏览器窗口能读取同一份库；编辑时检查版本，防止覆盖其他窗口的修改。
- 每次图片生成或修图提交后保存不可变的创作描述、人物设定、风格与模型；每张图片请求发送前，再保存实际完整提示词、画幅、质量及参考图顺序，随后关联结果图片或失败原因。队列取消和服务中断也保留记录，不自动重试。
- 记录支持“效果满意／一般／需要改进”评价和观察笔记，可将选定描述收录到共享库。复用填入描述、风格和模式，保留当前人物选择与参考图，生成前可继续调整。
- 从作品详情的“查看生成提示词”或任务面板的“查看提示词”直接追溯来源。删除图片或共享条目不会删除原始生成记录。
- 旧任务迁移已有创作描述，并明确标记未保存当时的完整请求；不会根据当前规则拼造旧请求。新记录逐张保存完整提示词。
- 历史分页读取，不受任务面板最近 100 条的限制。资料导出和完整备份包含全部提示词记录、评价及共享库，不含服务密钥。单条分享文件包含提示词与整理信息，不附带图片。

### 视觉反推与加权优化

- 在“优质参考”添加同一妆造的 1–8 张图片，可从作品库选取或上传。使用已配置的文本模型分析妆容、光线、肤质、构图及组图一致性，生成可编辑的反推提示词。反推属于视觉分析，无法确定原作者的原始提示词；截图箭头、页码、边框和水印排除在生成目标之外。
- 已录入用户提供的 9 张参考图，分为暖棕蜜桃、冷调猫眼、粉调亮片晚宴三组，并保存各自的反推提示词。AI 建议分单独展示；人工评分仍为空，避免将建议分冒充用户评价。用户已明确认可的参考方向可先参与优化，后续可采用建议分并调整。
- 默认权重：照片真实感 35、妆容表现 25、光线与肤质 20、构图与色彩 10、组图一致性 10。单项评分 0–5，加权总分为已评维度的归一化均值乘 20。空值表示未评或不适用，0 分则是真实的低分。单张图的 AI 一致性建议分为空。
- 权重、最低分和每次最多参考数量可调整，也可暂停自动优化。有评分的样本需满足最低分与至少 60% 的有效权重覆盖；取消认可的参考不参与。组图不适用的维度不提供优化方向。更换参考图片或目标风格会清除旧分析与旧评分。
- 优先采用相同风格的方向，再按已评状态、分数与样本优先级选择。不同风格仅借鉴摄影与质感，不覆盖当前妆容配色。标记“效果满意”的生成记录也会成为候选。
- 随机描述、AI 润色和最终出图均使用所选方向；显式人物设定、肤色、服装、妆容及修图范围优先。权重影响评分、选样与提示词重点，图片模型参数仍保持原配置。
- 每次图片任务入队时保存当时的权重、样本来源和提炼技法，最终完整请求逐张保存。以后更改权重或参考不会改写已有任务快照。资料导出和备份也包含参考组、分析及规则。

## 本轮已接入

- 项目、三语文案、收藏、模特档案、排期草稿及偏好保存到本机 SQLite。
- JPG / PNG / WebP 原图落盘，实际解码验证，生成缩略图。单张上限 20 MB、6000 万像素。
- GPT Image 图片生成和参考图编辑接口；结果自动进入作品库，空封面的关联项目采用第一张生成结果。
- 使用选定文本模型生成中文、英文和韩文，支持单语生成；保留锁定版本及生成期间的人工编辑。
- 任务历史、部分成功保留、取消剩余任务、服务中断提示。超时及中断不会自动重复提交收费请求。
- 服务配置、模型目录读取和连接验证。macOS 密钥保存到系统钥匙串，不写入浏览器持久存储、SQLite 或导出文件。
- 资料导出，以及包含有效原图、素材清单和 SHA-256 校验值的 JSON 备份。

## 服务配置与实测状态

在 **设置与连接 → 图片与文案服务** 设置地址、密钥和模型，再测试连接。已配置的密钥不会返回页面；留空会保留当前地址对应的密钥。不同地址的凭据彼此隔离。

本机当前配置：图片 `gpt-image-2`，文案 `gpt-6.1-sol`。模型目录和三语文案已通过真实验证。用户再次确认权限开启后，GPT Image 2 单张生成成功，约 49 秒返回 1086 × 1448 PNG；原图、600 × 800 缩略图、任务记录和项目封面均已保存。此前的分组权限 403 是历史失败记录，最新任务为 1/1 成功。本轮也已验证同组双图；跨妆造人物一致性和真实照片修图效果仍需更多实图验收。

自建模特档案会将人物参考图传给图片服务；内置示例档案仅提供人物描述。照片编辑会上传选中的原图，经旋转、去除元数据及必要缩放后发送。人物一致性与编辑效果取决于模型，需要实图验收。

用户提供的兼容服务为 HTTP，因此配置中明确允许 HTTP，设置页显示未加密传输说明。有效 HTTPS 证书可用时应切换到 HTTPS；应用没有关闭证书校验。

## 本地数据

默认目录：`~/Library/Application Support/YueZhuangStudio/`。

```text
studio.sqlite          工作空间、素材元数据、任务和非敏感服务配置
assets/<id>/           原图及缩略图
```

图片删除采用软删除，文件保留在应用目录；项目删除会保留内部归档。当前没有回收站、归档恢复或备份导入界面。导出备份包含当前有效资料，不含已删除图片、项目归档或密钥。

浏览器保留草稿副本及同步检查点。首次连接会迁移原型中的草稿和 IndexedDB 图片；迁移缺失图片时会提示并保留旧草稿。后端使用版本检查和冲突合并，避免用旧窗口覆盖已生成文案。页面导航仅影响当前窗口。

可用环境变量指定数据目录：

```bash
YZ_DATA_DIR="/absolute/path/to/yuezhuang-data" npm run dev
```

`.env.example` 是环境变量说明，程序不会自动加载 `.env`。不要把 API 密钥写入其中。非 macOS 环境暂仅在服务进程内保存密钥，重启后需重新输入。

## 当前边界

Instagram 授权、实际发布、定时执行、Electron 安装包和备份恢复界面尚未实现。发布月历只保存草稿，不会向任何账号发布。内置参考分为 6 张摄影示例和 48 张 AI 风格示例，均明确标注来源。

任务面板显示最近 100 条任务；提示词中心分页保留全部图片生成记录，导出也保留这些记录。当前资料保存在本机，没有部署在线库或提供跨设备同步。旧项目排期草稿继续兼容；快速工作流已支持关联作品组、选图和文案快照，Instagram 实发将在账号接入阶段完善。

